# FOS Educational Operating System

An educational operating system project built to explore and implement core OS internals. This project successfully passed 100% of its test scenarios and modules, demonstrating stable kernel-level operations, robust memory management, and process synchronization.

## 🚀 Key Features & Implementations

*   **Memory Management:** Designed a memory-efficient Dynamic Allocator, as well as Kernel and User Heaps utilizing a custom-fit allocation strategy.
*   **Paging & Fault Handling:** Implemented advanced Page Fault Handlers supported by multiple placement and replacement algorithms, including Clock, LRU, and Modified Clock.
*   **Process Communication:** Developed Shared Memory modules to allow secure and efficient data sharing between user processes.
*   **CPU Scheduling:** Built a Priority-based Round Robin Scheduler to effectively manage process execution and prevent CPU starvation.
*   **Kernel Protection & Synchronization:** Ensured system stability and prevented race conditions using SleepLocks, Semaphores, and Wait Channels.

## 🛠️ Technical Challenges Overcome

Building FOS required diving deep into low-level systems programming. Key milestones included:
*   Debugging complex kernel panics and tricky race conditions.
*   Managing shared resources efficiently across multiple processes.
*   Collaborating effectively under pressure to maintain a stable build environment while pushing major kernel updates.
